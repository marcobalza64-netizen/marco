# Spettro Frequenza (solo programma Python)

Solo l’app spettro. Nessun altro programma in questo ZIP.

## Avvio
1. Estrai lo ZIP
2. Installa Python 3: https://www.python.org/downloads/
3. Mac: doppio clic su `avvia.command`
   Windows: doppio clic su `avvia.bat`
   Linux: `chmod +x avvia.sh && ./avvia.sh`

Oppure da terminale:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python spectrum_visualizer.py
```

Consenti il microfono. Chiudi la finestra per uscire.

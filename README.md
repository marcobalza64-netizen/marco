# Somma Numeri

App Python per sommare numeri. Due modi per usarla: **web** (consigliato) o **terminale**.

## App web (browser)

```bash
python3 app.py
```

Si apre su [http://127.0.0.1:8765](http://127.0.0.1:8765).  
Aggiungi i numeri, calcola la somma, rimuovi o svuota la lista. Premi `Ctrl+C` per chiudere.

Nessuna dipendenza esterna: usa solo la libreria standard di Python.

## App terminale

```bash
python3 somma.py
```

Inserisci i numeri uno alla volta. Digita `fine` (o lascia vuoto) per vedere la somma.
